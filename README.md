# 🕸️ GraphFun

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://graphfun.abdlhamid-bilal.de/)
[![GitHub License](https://img.shields.io/github/license/abdlhamid-bilal/GraphFun)](https://github.com/abdlhamid-bilal/GraphFun/blob/main/LICENSE)

**GraphFun** is an interactive web tool that allows users to visually build graphs and apply the famous **Dijkstra algorithm** to calculate the shortest path between two nodes. Perfect for students, educators, or anyone who wants to explore graph theory in a fun and interactive way!

---

## 🚀 Live Demo

Try the project directly here:  
**👉 [graphfun.abdlhamid-bilal.de](https://graphfun.abdlhamid-bilal.de/)**

## ✨ Features

* **Interactive Graph Builder:** Create nodes and connect them with edges using simple point-and-click actions directly in your browser.
* **Edge Weights:** Assign individual weights or distances to your connections.
* **Dijkstra's Algorithm:** Run the algorithm in real-time to calculate and visually highlight the shortest path from a start node to a target node.
* **Intuitive User Interface:** Clean and simple design for maximum usability.

## 🛠️ Technologies

This project is built using vanilla web technologies, keeping it lightweight and fast without the need for external frameworks:
* **HTML5** for structure
* **CSS3** for styling and animations
* **JavaScript (ES6+)** for the interactive logic and the Dijkstra algorithm implementation

## 💻 Local Installation

If you want to run or develop the project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/abdlhamid-bilal/GraphFun.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd GraphFun
   ```

3. **Run the project**
   Since this is a standard frontend application, no build steps or dependencies are required. Simply open the `index.html` file in your browser, or use a local development server (e.g., Live Server extension in VS Code).

## 📖 Usage Guide

1. Click anywhere on the canvas to create new **nodes**.
2. Connect two nodes to create an **edge** and define its weight (distance).
3. Select a **start node** and a **target node**.
4. Run the algorithm – the **shortest path** will be calculated and visually highlighted immediately!
